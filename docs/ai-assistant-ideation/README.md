# Design documents

Each file here is a brainstorm, spec or plan written for one knot ticket, named by the ticket's
id, and attached to that ticket as a commit-pinned note. They were produced with AI assistance
inside the maintainer's review harness, so they mention review roles, gates and commit hooks that
live in that environment rather than in this repository. They are kept because they record why
the code is shaped as it is; nothing in the package depends on them.
