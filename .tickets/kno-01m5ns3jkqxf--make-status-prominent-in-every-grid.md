## Description

Every ticket row shows its status as a pill the size of the priority badge, in a fixed-width column, coloured by the role the status plays in the project's configuration: the initial status, the active status, the stages between, the first terminal status and the other terminal statuses. Rows in a terminal status recede. The ticket page header carries the same pill, larger.
